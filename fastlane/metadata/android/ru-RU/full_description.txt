Приложение для сайта exch.cx.

Возможности:
- Импортировать текущие активные заявки в приложение, чтобы отслеживать их внутри приложения
- Автоматически проверять периодически обновления заявок в фоновом режиме, отправляя вам уведомление о новом состоянии или ошибке
- Автоматически проверять сообщения чата поддержки заявок, отправляя вам уведомление при появлении нового сообщения
- Автоматически запросить удаление данных о заявках после выполнения заявки
- Позволяет хранить данные заказа локально на телефоне в течение неопределенного времени
- Позволяет установить api ключ для запросов (если он у вас есть)
- Позволяет выбрать, использовать ли луковый адрес Tor для соединений или нет
- Позволяет установить прокси для соединений
- Позволяет настроить уведомление при изменении резервов
- Приложение полностью с открытым исходным кодом

Возможности eXch.cx:
- Без регистрации
- Без Cloudflare
- Никаких задержек
- Никаких скрытых платежей
